# Pilots

**No pilot has happened yet.** This page is a placeholder with headings
only; it gets filled in after the first real pilot, from what actually
happened — including what did not work. Nothing may be written here before
then: no users, no events, no transaction hashes, no outcomes.

When a pilot runs, one file per pilot goes here, named for the participant
at whatever level of detail they consented to (`{name}.md`), with these
headings:

## Template (headings only — do not fill until a real pilot happens)

```markdown
# eventbadges × {pilot group} pilot

Status: testnet pilot. Not a production deployment.

## Purpose
What this pilot tests, in one or two sentences.

## What eventbadges is responsible for
List it plainly.

## What the pilot group is responsible for
List it plainly, even if it is just "using the app and giving feedback."

## What happened
Dates, what was tried, real transaction links, what confused the tester,
what changed as a result. Written after the pilot, not before.

## What this does not prove
One or two sentences, consistent with limitations.md.
```

Related: the [pilot playbook](../pilot-playbook.md) (how a pilot is run and
the deployment gate) and [known limitations](../limitations.md) (the
pilot-evidence boundary).
